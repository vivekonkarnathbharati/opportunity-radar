# OpportunityRadar 🎯

A smart student opportunity and career matcher built for the H2S Hackathon.

## Overview
OpportunityRadar bridges the gap between students and career opportunities by matching users to internships, hackathons, and workshops based on their verified skills.

PPT = https://gamma.app/docs/OpportunityRadar--azg0t6y4lylyeui

## Core Features
- **Dynamic Skill & Type Filtering:** Real-time matching against curated tech roles.
- **Localized Opportunities:** Curated for computer science undergraduates in Pune and Maharashtra.
- **AI Cold Application Generator:** Generates a personalized 3-sentence outreach note for any selected opportunity with 1-click clipboard copying.

## Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS
- **Bundler:** Vite
- **Icons:** Lucide React
